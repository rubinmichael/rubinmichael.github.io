# Michael A. Rubin — personal website

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted free on GitHub Pages at https://rubinmichael.github.io.

## Where things live

| To change...                           | Edit this file             |
|----------------------------------------|----------------------------|
| Home page text                         | `_pages/about.md`          |
| Publications and working papers        | `_pages/research.md`       |
| CV page                                | `_pages/cv.md`             |
| Courses                                | `_pages/teaching.md`       |
| Contact info / office hours            | `_pages/contact.md`        |
| Sidebar (photo, title, profile links)  | `_config.yml` (`author:`)  |
| Menu across the top                    | `_data/navigation.yml`     |
| PDFs and other downloads               | put them in `files/`; they appear at `/files/<name>.pdf` |

Changes go live a minute or two after they are pushed to GitHub. You can also edit any file directly on github.com (open the file, click the pencil icon, then "Commit changes").
